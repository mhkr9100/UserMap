## 2024-05-09 - Pre-compiled RegEx over dynamic instantiation in tight loops
**Learning:** In text processing or scoring loops like `prismMemoryExtractor.ts`, dynamically creating new RegExp objects (e.g. `new RegExp(m.source, 'gi')`) inside loops creates unnecessary CPU overhead and garbage collection pressure. Furthermore, string operations like `.toLowerCase()` allocate new strings on the heap unnecessarily since regular expressions can handle case insensitivity via the 'i' flag natively.
**Action:** Pre-compile regular expressions at the module scope with the necessary flags ('g' and 'i'), and use `String.prototype.match()` to safely execute against strings directly without explicitly coercing `.toLowerCase()`. String match natively returns all instances without modifying the state.
