## 2024-05-24 - Fix SQL Injection (LIKE) and HTTP Parameter Pollution in Logs API
**Vulnerability:** Unescaped user input in SQLite `LIKE` queries and missing type validation for Express `req.query` parameters allowed SQL Wildcard Injection and HTTP Parameter Pollution (HPP).
**Learning:** `req.query` values in Express can be arrays or objects instead of strings. Casting them to `Record<string, string>` does not enforce the type at runtime. If an array is passed and interpolated into a SQL query, it can cause database errors or bypass filters. Additionally, SQLite requires explicit escaping for `%` and `_` wildcards in `LIKE` queries using the `ESCAPE '\'` clause to prevent wildcard injection (DoS or information disclosure).
**Prevention:** Always validate `req.query` inputs at runtime using `typeof input === 'string'` before using them. When building `LIKE` clauses, explicitly escape user input with `.replace(/[%_\\]/g, '\\$&')` and append `ESCAPE '\'` to the SQL query.
