## 2025-02-23 - Prevent SQL Wildcard Injection & HTTP Parameter Pollution
**Vulnerability:** The `/logs` API Endpoint had a Denial of Service vulnerability (Wildcard Injection) and a Crash vulnerability (HTTP Parameter Pollution). It allowed users to supply unescaped SQL `LIKE` wildcards (`%` and `_`) which could force expensive table scans. Furthermore, it assumed the Express `req.query.search` variable was always a string, which could be an array/object causing `.replace()` to crash (500 Error).
**Learning:** SQLite requires explicitly declaring `ESCAPE '\'` (using `ESCAPE '\\'` in JS string literals) to escape `LIKE` wildcards. Also, in Express, query parameters can be arrays/objects, requiring explicit `typeof input === 'string'` checks before performing string methods to avoid server crashes.
**Prevention:** Always validate Express query parameters with `typeof input === 'string'` before casting or running string operations. For SQL `LIKE` queries, safely escape user input using `.replace(/[%_\\]/g, '\\$&')` and append the `ESCAPE '\\'` clause to the query string.
